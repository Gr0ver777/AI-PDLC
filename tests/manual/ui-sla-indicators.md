# Manual TC: SLA-индикаторы обработки заявки

## Цель

Проверить frontend-only блок `SLA обработки` в форме реструктуризации.

## Предусловия

- Frontend запущен на `http://localhost:5173`.
- Backend может быть недоступен: для проверки используется Playwright route mocking.

## Тестовые данные

- Клиент: `ООО Автотест Реструктуризация`
- Дедлайн обработки: дата в пределах 3 дней от текущей даты
- Срочность: `Повышенная`
- Комментарий: `Проконтролировать контакт до дедлайна`

## Шаги

1. Открыть рабочую панель AI-PDLC.
2. Перейти в раздел `Реструктуризация`.
3. Проверить, что отображается блок `SLA обработки`.
4. Очистить поле `Дедлайн обработки`.
5. Нажать `Создать заявку`.
6. Заполнить дедлайн датой в пределах 3 дней.
7. Выбрать срочность `Повышенная`.
8. Заполнить комментарий по SLA.
9. Нажать `Создать заявку`.
10. Проверить карточку созданной заявки.
11. Перейти в раздел `Банкротство`.

## Ожидаемый результат

- На шаге 5 форма не отправляется из-за browser validation.
- После ввода дедлайна в пределах 3 дней отображается SLA-статус `Под контролем`.
- Карточка заявки содержит блок `SLA обработки` с дедлайном, срочностью, статусом и комментарием.
- В форме банкротства блок `SLA обработки` не отображается.

## Результат ручной проверки

`PASS_WITH_MOCK`

Проверка выполняется через Playwright route mocking, так как фича frontend-only.
