# Релиз

## MVP release checklist

- Backend запускается через Gradle Wrapper.
- Frontend собирается через Vite.
- H2 file DB создается локально.
- Happy-path тест-кейсы описаны в `docs/test-cases/happy-path.md`.
- UI автотесты запускаются через pytest.
- README содержит команды локального запуска.

## Ограничения релиза

- Нет реальной интеграции с банковскими системами.
- Нет внешней LLM-интеграции.
- Авторизация и роли не реализованы.
