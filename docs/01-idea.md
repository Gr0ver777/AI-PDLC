# Идея

AI-PDLC — демонстрационный продукт для имитации работы банковского отдела проблемных активов.

Цель MVP: показать, как заявки по проблемным активам проходят от ввода данных до AI-оценки риска и решения оператора. Система не подключает внешние LLM и использует прозрачные правила, чтобы результат был воспроизводимым для демо и автотестов.

Основные роли:

- Оператор отдела проблемных активов создает и обрабатывает заявки.
- Руководитель смотрит очередь, риски и эскалации.
- Senior QA поддерживает happy-path тест-кейсы и автотесты.
