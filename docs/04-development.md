# Разработка

## Backend

REST API расположен в модуле `backend`. Основные слои:

- Controller принимает HTTP-запросы.
- Service управляет созданием заявок и решениями оператора.
- AI assessment service рассчитывает риск, приоритет и рекомендацию.
- Repository работает с PostgreSQL через Spring Data JPA.

Локальная база поднимается командой:

```powershell
docker compose up -d postgres
```

Backend запускается командой:

```powershell
cd backend
.\gradlew.bat bootRun
```

Настройки подключения можно переопределить переменными:

- `AI_PDLC_DB_URL`
- `AI_PDLC_DB_USER`
- `AI_PDLC_DB_PASSWORD`

## Frontend

React UI расположен в модуле `frontend`. Экран первого запуска - рабочая панель отдела, без маркетинговой посадочной страницы.

Ключевые состояния UI:

- список заявок;
- фильтры;
- форма реструктуризации;
- форма банкротства;
- карточка заявки;
- уведомление об ошибке или успешном действии.

## Новые фичи

Каждая новая доработка начинается в отдельной feature-ветке от актуального `main`. Рекомендуемый формат имени ветки:

```text
codex/pdlc-<feature-slug>
```

PDLC flow фиксирует отдельные коммиты для требований, QA review, ручных тестов, разработки и автотестов.
