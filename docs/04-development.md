# Разработка

## Backend

REST API расположен в модуле `backend`. Основные слои:

- Controller принимает HTTP-запросы.
- Service управляет созданием заявок и решениями оператора.
- AI assessment service рассчитывает риск, приоритет и рекомендацию.
- Repository работает с H2 через Spring Data JPA.

## Frontend

React UI расположен в модуле `frontend`. Экран первого запуска — рабочая панель отдела, без маркетинговой посадочной страницы.

Ключевые состояния UI:

- список заявок;
- фильтры;
- форма реструктуризации;
- форма банкротства;
- карточка заявки;
- уведомление об ошибке или успешном действии.
