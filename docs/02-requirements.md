# Требования

## Функциональные требования

- Пользователь видит рабочую панель со списком заявок.
- Пользователь создает заявку на реструктуризацию.
- Пользователь создает заявку на банкротство.
- Backend рассчитывает риск `LOW`, `MEDIUM`, `HIGH`, приоритет и рекомендацию.
- Пользователь открывает карточку заявки и видит историю событий.
- Пользователь применяет решение: принять, запросить документы, эскалировать.
- Данные хранятся локально в H2 file DB.

## Нефункциональные требования

- Frontend: React + TypeScript + Vite.
- Backend: Spring Boot 4, Java 21.
- Автотесты: Python, pytest, Playwright, Allure.
- UI и документация на русском языке.
