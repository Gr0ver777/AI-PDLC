# Тестирование

Тестирование строится от документации к автотестам:

1. Senior QA описывает happy-path тест-кейсы.
2. По тест-кейсам создаются Playwright автотесты на Python.
3. Автотесты используют Page Object, Page Factory и Page Element.
4. После генерации автотесты запускаются локально против frontend и backend.
5. Ошибки исправляются в приложении или тестах, затем запуск повторяется.

Минимальные проверки backend выполняются через Spring Boot test.
