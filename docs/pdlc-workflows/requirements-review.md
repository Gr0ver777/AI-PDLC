# PDLC Workflow: Review требований Senior QA

## Цель

Проверить новые закоммиченные требования до разработки тест-кейсов и автотестов.

## Вход

- Новый или измененный файл требований в `docs/requirements/`.
- Git diff или последний коммит требований.

## Проверки

Senior QA проверяет:

- требование содержит бизнес-цель и пользователя;
- описаны поля, обязательность, допустимые значения и ограничения;
- есть критерии приемки;
- понятно, меняется ли backend contract;
- есть тестопригодные ожидаемые результаты;
- указаны ограничения MVP и зависимости от окружения;
- нет противоречий с существующими сценариями.

## Выход

Создать markdown-отчет в `docs/qa-reviews/`:

- статус review: `PASS`, `PASS_WITH_RECOMMENDATIONS` или `NEEDS_REWORK`;
- найденные риски;
- рекомендации;
- решение, можно ли переходить к ручным тест-кейсам.

Если статус `NEEDS_REWORK`, ручные тест-кейсы не создаются до исправления требований.
