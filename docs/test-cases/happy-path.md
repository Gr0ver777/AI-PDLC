# Happy-path тест-кейсы

## TC-001 Создание заявки на реструктуризацию

Предусловия: backend и frontend запущены.

Шаги:

1. Открыть UI.
2. Перейти в раздел `Реструктуризация`.
3. Заполнить обязательные поля валидными данными.
4. Нажать `Создать заявку`.

Ожидаемый результат: открыта карточка заявки, отображается AI-рекомендация и уровень риска.

## TC-002 Создание заявки на банкротство

Шаги:

1. Открыть UI.
2. Перейти в раздел `Банкротство`.
3. Заполнить обязательные поля валидными данными.
4. Нажать `Создать заявку`.

Ожидаемый результат: открыта карточка заявки на банкротство, отображаются стадия процесса, судебное дело и AI-рекомендация.

## TC-003 Просмотр карточки заявки

Шаги:

1. На рабочей панели выбрать существующую заявку.
2. Нажать `Открыть`.

Ожидаемый результат: отображается карточка с общими полями, модульными полями, риском, рекомендацией и историей.

## TC-004 Фильтрация списка

Шаги:

1. Создать заявку на реструктуризацию.
2. Вернуться на рабочую панель.
3. В фильтре `Модуль` выбрать `Реструктуризация`.

Ожидаемый результат: в таблице отображаются заявки выбранного модуля.

## TC-005 Применение решения оператора

Шаги:

1. Открыть карточку заявки.
2. Нажать `Эскалировать`.

Ожидаемый результат: статус заявки изменен на `Эскалировано`, в истории добавлено событие решения оператора.
